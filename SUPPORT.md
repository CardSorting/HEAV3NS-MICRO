# Support

For operational questions, architecture diagnostics, or troubleshooting:

1. Run the built-in runtime diagnostics:
   ```bash
   cargo run --release -- --smoke
   cargo run --release -- --flight
   ```
2. Run the Joyzoning architectural doctor:
   ```bash
   node /Users/bozoegg/Desktop/HEAV3NS-JOY/bin/joy-check.mjs . --doctor
   ```
3. Consult [`AGENTS.md`](AGENTS.md), [`docs/README.md`](docs/README.md), and [`docs/PROJECT_MAP.md`](docs/PROJECT_MAP.md).
